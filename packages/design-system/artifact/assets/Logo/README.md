# Logo

Les fichiers du logo de LetterOn, en SVG.

- `mark.svg` : le symbole seul (enveloppe en verre corail et soleil), fond transparent, pour les fonds papier ou sombres.
- `app-icon.svg` : le symbole en verre blanc sur le carré corail. Pour l'icône de l'extension, le favicon et les stores.
- `app-icon-dark.svg` : la même icône sur le carré nuit prune, pour les thèmes sombres.
- `app-icon-small.svg` : la version plate, sans flou ni dégradé, pour 16 à 32 px (favicon, barre d'outils Chrome).

Le lockup horizontal (symbole + « letteron ») est du texte : utiliser le composant `Logo` ou `Wordmark` plutôt qu'un SVG. Règles : un espace libre d'au moins la moitié du symbole autour, jamais étiré, jamais recoloré.
