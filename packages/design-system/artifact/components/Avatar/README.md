# Avatar

Un rond avec la photo ou les initiales d'une personne. Sans `tone`, la couleur (coral, sun ou mint) est déduite du nom et ne change donc pas d'un écran à l'autre.

- Tailles : `sm` 32 px (listes compactes), `md` 44 px (cartes), `lg` 64 px (profil).
- `name` est obligatoire : il sert aussi de libellé accessible.
