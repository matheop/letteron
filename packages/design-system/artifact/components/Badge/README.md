# Badge

Un ou deux mots de statut, en pilule. `neutral` pour l'info, `coral` pour ce qui demande ton attention (« Not verified »), `sun` pour ce qui est nouveau ou à compter (« 12 to read »), `mint` uniquement pour une réussite (« Archived », « Verified »).

Le texte suffit à comprendre le statut, sans se fier à la couleur seule.
