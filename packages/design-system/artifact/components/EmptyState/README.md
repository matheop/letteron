# EmptyState

Ce qu'on montre quand il n'y a rien à montrer, pour ne jamais laisser croire que les bookmarks ont disparu.

- `size="lg"` (titre `display`, pastille de 104 px) pour l'onboarding et la file vide ; `md` (titre `heading`) pour une recherche sans résultat ou une collection vide.
- Pastille : `coral` (neutre), `sun` (à fêter : « You're all caught up! »), `mint` (réussi).
- Un titre qui dit la situation, une phrase qui dit quoi faire, puis les actions en `children` (une seule `primary`).
