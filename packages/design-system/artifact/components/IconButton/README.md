# IconButton

Un bouton rond qui ne montre qu'une icône : menu mobile, actions au survol d'un bookmark, fermer. Le `label` est obligatoire : il devient le nom accessible et l'infobulle.

- `ghost` (par défaut) posé sur un fond, `secondary` avec fond `surface` et filet `line` quand il flotte sur une carte.
- `md` 44 px, `sm` 36 px (actions d'une carte).
- `tone="danger"` passe l'icône en `coral-strong` (Delete).
