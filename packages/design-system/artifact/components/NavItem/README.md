# NavItem

Une entrée de la barre latérale : « To read » (écran d'arrivée, compteur `sun`), « Archive », puis une entrée par collection avec sa pastille de couleur (`dot`, un nom de token) et son compteur. L'entrée courante (`current`) prend le fond `coral-soft` et le texte `coral-strong`.

La barre latérale fait 248 px : `Wordmark`, les entrées principales, le libellé « Collections » en `caption`, les collections, un `Button` ghost « New collection » (icône `plus`), puis les tags en `Chip`. Sur mobile, elle se replie derrière un `IconButton` « menu ».
