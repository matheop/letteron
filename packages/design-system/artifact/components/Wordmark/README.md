# Wordmark

Le logo horizontal de LetterOn (symbole + « letteron »), en trois tailles de texte : `md` (22 px) dans la barre latérale et les en-têtes, `lg` (28 px) sur les pages de connexion, `xl` (36 px) pour les grands moments. C'est `Logo` avec `variant="lockup"` : préfère `Logo` dès qu'il faut un autre ton (une couleur, inversé) ou le symbole seul.
